================================================================================
PROJECT OVERVIEW
================================================================================

The Ooredoo IA Benchmark dashboard is a comprehensive platform for:
- Evaluating LLM models across department-specific use cases
- Providing role-based access (clients see their dept only, admins see all)
- Generating AI-powered recommendations with real metric justifications
- Comparing model performance across multiple metrics

Scope: 6 departments, 56 active executions, 99 modern benchmark scores
